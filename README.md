AUTO SLICE — SPACED CONVEYOR UPDATE (V3)
=========================================
1. Extract the ZIP.
2. Double-click START_GAME.bat.
3. Watch the fruits/vegetables arrive one-by-one from the far end of the conveyor.

V3 CHANGES:
- Items spawn at the far/narrow end of the belt.
- Only one fruit/vegetable spawns per interval.
- Items travel toward the viewer in a spaced-out queue.
- Each item follows a different lane; the belt widens in perspective.
- The automatic knife sweeps across the cutting line.
- No more fruit/vegetable pile-up at the cutting board.

Pure HTML/CSS/JavaScript; no external libraries or internet.
